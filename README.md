# Futurology Lab

Աշակերտական կայքերի փորձարարական տարածք։

## Կառուցվածք

- `index.html` — լաբորատորիայի գլխավոր էջ
- `style.css` — գլխավոր էջի ձևավորում
- `group1/` — առաջին խմբի ինքնուրույն կայք
- `group2/` — երկրորդ խմբի ինքնուրույն կայք

Յուրաքանչյուր խումբ փոխում է միայն իր թղթապանակի `index.html`, `style.css` և `script.js` ֆայլերը։
